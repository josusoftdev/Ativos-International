## 🚀 Tecnologias

- **Next.js 16.2.0** - Framework React com suporte a SSR e SSG
- **React 19.2.4** - Biblioteca de UI
- **TypeScript 5** - Tipagem estática para JavaScript
- **Tailwind CSS 4** - Utility-first CSS framework
- **Lucide React** - Ícones SVG
- **ESLint 9** - Análise de código estática

## 📋 Funcionalidades

- 🔐 **Autenticação** - Sistema de login e registro de usuários
- 💼 **Dashboard** - Painel de controle centralizado
- 📊 **Gerenciamento de Carteiras** - Criar e gerenciar carteiras de criptomoedas
- 📈 **Planos de Investimento** - Visualizar e gerenciar diferentes planos
- 📰 **Notícias** - Seção de notícias sobre criptomoedas
- ❓ **FAQ** - Perguntas frequentes
- ℹ️ **Sobre** - Página informativa sobre a aplicação


## 📱 Páginas Principais

| Página | Rota | Descrição |

| Dashboard | `/` | Painel principal da aplicação |

## 📝 Notas de Desenvolvimento

- O projeto usa o **App Router** do Next.js (diretório `app/`)
- Todos os componentes estão estruturados em subpastas organizadas
- A aplicação usa **Tailwind CSS** para estilização
- TypeScript é obrigatório para melhor qualidade de código
- Componentes de UI são reutilizáveis e seguem padrões de design
